# Emad Portfolio — Next.js + TypeScript

نسخهٔ Next.js همان وب‌سایت ساخته‌شده از فایل فیگما، همراه با تمام اصلاح‌های تأییدشده: هدر کوچک و ثابت، آیکون واتساپ، بخش پژوهش بازشونده، کارت‌های آمار، فوتر و انیمیشن ورود بخش‌ها هنگام اسکرول.

## اجرای پروژه

پیش‌نیاز: **Node.js 20.9 یا جدیدتر** و npm. نسخهٔ فعلی با **Node.js 22.6.0** هم آزمایش شده است. دستورها را در پوشهٔ همین پروژه اجرا کنید:

```bash
npm ci
npm run dev
```

سپس [پیش‌نمایش محلی](http://127.0.0.1:3000) را باز کنید.

ساخت و اجرای نسخهٔ production:

```bash
npm run typecheck
npm run build
npm start
```

برای پورت دلخواه، مثلاً `4173`:

```bash
npm start -- --port 4173
```

این پروژه از Next.js App Router، React، TypeScript با `strict` و Tailwind CSS 4 از طریق PostCSS استفاده می‌کند. نسخهٔ دقیق وابستگی‌ها در `package-lock.json` ثبت شده است. Build با Webpack انجام می‌شود؛ اجرای توسعه از تنظیم پیش‌فرض Next.js استفاده می‌کند.

## بررسی نسخهٔ منتقل‌شده، پیش از اتصال لینک‌ها

- ساخت production با `npm run build` و بررسی نوع‌ها با `npm run typecheck` موفق بودند.
- نسخهٔ توسعه با Turbopack اجرا شد و صفحه پاسخ `200` داد. صفحهٔ اصلی production، فونت و رزومه پاسخ `200` و مسیر ناموجود پاسخ `404` دادند.
- محتوای مهارت‌ها، پژوهش و آمار در HTML تولیدشده وجود دارد؛ شناسهٔ تکراری دیده نشد.
- در مرورگر، عرض‌های `320`، `390`، `768`، `1024` و `1395` پیکسل در حالت پژوهش باز بررسی شدند و اسکرول افقی ناخواسته دیده نشد.
- منوی موبایل، بستن با Escape، باز و بسته‌شدن پژوهش با کلیک و صفحه‌کلید، دیالوگ تماس از Hero و فوتر، ذخیرهٔ پیام آزمایشی، بازگشت فوکوس و پیام واتساپ بررسی شدند.
- ورود بخش با اسکرول، تغییر opacity از `0` به `1` و حالت `is-revealed` را نشان داد. در بررسی مرورگر خطا یا هشدار ثبت نشد.
- گزارش قابل خواندن ماشین در `verification.json` است. این بررسی‌ها روی Windows و با Node.js `22.21.1` انجام شدند.

## رفع خطای ERR_REQUIRE_ESM در Node.js 22.6

نسخهٔ قبلی Tailwind `4.3.5`، بستهٔ `magic-string` از شاخهٔ `1.x` را با `require()` بارگذاری می‌کرد. این ترکیب روی Node.js `22.6.0` خطای `ERR_REQUIRE_ESM` می‌داد. اشارهٔ خطا به `globals.css` مربوط به مرحلهٔ پردازش CSS بود.

برای سازگاری، نسخهٔ `tailwindcss` و `@tailwindcss/postcss` روی `4.1.18` ثابت شده و فایل قفل نیز به‌روز شده است. وابستگی `magic-string` اکنون از شاخهٔ سازگار `0.30.x` نصب می‌شود. هیچ فایلی داخل `node_modules` به‌صورت دستی دست‌کاری نشده است.

اگر سرور قبلی هنوز باز است، با `Ctrl+C` ببندید و دوباره `npm run dev` را اجرا کنید. پس از دریافت نسخهٔ جدید در پوشه‌ای دیگر، ابتدا `npm ci` را اجرا کنید.

با Node.js `22.6.0`، بارگذاری افزونهٔ PostCSS، Build و بررسی TypeScript موفق بودند. اجرای توسعه با Turbopack و اجرای production نیز برای صفحه و فایل CSS پاسخ `200` دادند. ظاهر و کامپوننت‌های سایت تغییر نکرده‌اند.

## رزومهٔ PDF ارسالی

فایل ارائه‌شده با نام اصلی `Emad_Aghahosseini_CV.pdf` در `public` قرار دارد. فایل PDF بدون تغییر محتوا کپی شده است و دو صفحهٔ آن در مسیر `/cv` با پیش‌نمایش تصویری نمایش داده می‌شوند. فایل اصلی از دکمهٔ «Download PDF» قابل دانلود است.

هر دو دکمهٔ هدر و Hero از `siteConfig.cvUrl` و مسیر `/cv` استفاده می‌کنند. پیش‌نمایش صفحهٔ رزومه HTML و تصویر است؛ برای دیدن آن به PDFخوان بومی مرورگر نیازی نیست. برای به‌روزرسانی رزومه در آینده، فایل PDF و تصاویر متناظر در `public/assets/cv` را با هم به‌روز کنید. مشخصات تصاویر در `src/lib/cv-pages.ts` قرار دارد.

Build و بررسی TypeScript موفق بودند. در نسخهٔ توسعه، صفحهٔ `/cv`، هر دو تصویر و PDF اصلی پاسخ `200` دادند. باز شدن صفحه با کلیک روی دکمهٔ اصلی در مرورگر بررسی شد و هر دو تصویر بارگذاری شدند. دانلود فایل اصلی نیز روی مرورگر آزمایش شد و محتوای فایل دریافت‌شده با فایل ارسالی مطابقت داشت.
